# i-bot-d

Тестировщик стратегий и программа торговли для фьючерсов Binance USD-M. Тестировщик перебирает параметры идеи на истории и отдаёт отобранные строки конфигом бота; торговая программа ведёт по ним сделки. Площадка обеих — Binance USD-M, другую биржу эта версия не подключает. Постановка — в [docs/SPEC.md](docs/SPEC.md). Как устроен уже собранный тестировщик — в [docs/CODE.md](docs/CODE.md).

Торговля, сторож и заявки на биржу в этом коде ещё не сделаны. Тестировщик ордера не отправляет.

## Запуск

Команды из корня репозитория. Один раз поставить зависимости:

```bash
npm install
python3 -m venv backend/.venv
backend/.venv/bin/pip install -r backend/requirements.txt
```

Дальше два процесса:

- `npm run tester` — Python API и воркер на `http://127.0.0.1:8787`.
- `npm run tester:web` — экран React (Vite) на `http://127.0.0.1:5173`.

`npm run build:web` собирает интерфейс в `apps/tester/dist`. Пока сборки нет, адрес `8787` без второго процесса показывает только подсказку открыть `5173`. Ряды цен и результаты прогонов пишутся в `data/` и в репозиторий не входят.
