# i-bot-d

Тестировщик стратегий и программа торговли для фьючерсов Binance USD-M. Тестировщик перебирает параметры идеи на истории и отдаёт отобранные строки конфигом бота; торговая программа ведёт по ним сделки. Площадка обеих — Binance USD-M, другую биржу эта версия не подключает. Постановка — в [docs/SPEC.md](docs/SPEC.md). Как устроен уже собранный тестировщик — в [docs/CODE.md](docs/CODE.md).

Торговля, сторож и заявки на биржу в этом коде ещё не сделаны. Тестировщик ордера не отправляет.

## Запуск

Команды из корня репозитория. Один раз поставить зависимости:

```bash
npm install
python3 -m venv backend/.venv
backend/.venv/bin/pip install -r backend/requirements.txt
```

Дальше два процесса:

- `npm run tester` — Python API и воркер на `http://127.0.0.1:8787`.
- `npm run tester:web` — экран React (Vite) на `http://127.0.0.1:5173`.

`npm run build:web` собирает интерфейс в `apps/tester/dist`. Пока сборки нет, адрес `8787` без второго процесса показывает только подсказку открыть `5173`. Ряды цен и результаты прогонов пишутся в `data/` и в репозиторий не входят.

## Число процессов прогона

По умолчанию сетку считают `max(1, доступные_ядра // 2)`. Доступные ядра — `sched_getaffinity`, если этого вызова нет — `os.cpu_count`. На одном ядре остаётся один процесс.

Задать число до запуска сервера, целым от 1:

```bash
IBOT_WORKERS=4 npm run tester
```

Значение больше числа ядер обрезается до него, поэтому переменная может занять все ядра. Ноль, дробь, текст и отрицательное число не берутся: остаётся половина ядер, в журнал пишется одна строка. Переменная читается процессом, который уже запущен, поэтому её меняют до `npm run tester`.

На экране «Сетка» поле «Потоки» задаёт число для этого прогона и для оценки скорости. Заполненное поле важнее переменной, сервер для этого перезапускать не нужно. В поле заранее стоит половина ядер. Верх поля — на одно ядро меньше, чем доступно, чтобы одно ядро осталось системе. Пустое поле оставляет переменную или, если её нет, ту же половину.

Число процессов не меняет формулы стратегии: те же параметры дают те же строки результата.
